# Hai — protótipo das telas do MVP

Abra `index.html` no navegador. O protótipo é estático e funciona sem instalação ou servidor.

## Telas

1. Início do jovem
2. Catálogo de experiências
3. Página da experiência
4. Desafio e envio da entrega
5. Perfil e portfólio, com prévia e controles de visibilidade
6. Painel da empresa
7. Avaliação humana com rubrica
8. Briefing para criação assistida da experiência

As interações e os dados são locais e ilustrativos. O envio da entrega, a avaliação e o briefing ficam apenas na sessão aberta do navegador. O protótipo não tem autenticação, banco de dados, publicação de portfólio ou contato com candidatos.

## Direção visual

- Cor principal: `#087F8C`
- Teal escuro: `#064B55` para contraste e textos de destaque
- Branco: `#FFFFFF` para superfícies
- Fundo: `#F7FAF9` para separar o conteúdo das superfícies
- Menta: `#DFF3EF` para progresso e estados positivos
- Pêssego: `#FFE8DD` para notas de apoio e avatares
- Areia: `#FFF0D9` para estados pendentes

A logo anexada foi incorporada em `logo-data.js` para que o protótipo permaneça portátil, mesmo aberto diretamente como arquivo local.
